# Data Santri Qiraati Cabang Surabaya

Aplikasi web dashboard dan pendataan santri Qiraati untuk cabang Surabaya dengan visualisasi analitik interaktif (Chart.js) dan styling modern (Tailwind CSS).

## Fitur Utama
1. **Dashboard Statistik**:
   - Total TPQ, Total Santri, Santri Dasar, Santri PRA & PTPT.
   - Grafik Sebaran TPQ per Kecamatan di Surabaya.
   - Diagram Komposisi Jenjang Santri.
   - Akumulasi Santri per Kategori Kelas (1A s/d 5B, Imtas, Khotaman, PRA 1-5, PTPT 1-6).
2. **Formulir Input Data**:
   - Pilihan Kecamatan & Nama TPQ dinamis.
   - Form isian detail setiap kelas.
3. **Rekapitulasi Data**:
   - Filter pencarian instan berdasarkan Nama TPQ, Kecamatan, dan Bulan.
   - Kartu rincian per TPQ.

## Cara Menggunakan Secara Lokal
Cukup klik dua kali (double click) file `index.html` di komputer Anda untuk membukanya di browser apa saja (Google Chrome, Edge, Firefox).
